# ASTRAVA Portfolio — Project Context

## Purpose
The public-facing website for ASTRAVA, an independent three-person digital studio. It should explain the studio, present genuine work, describe relevant services, and make it easy to start a conversation.

## Initial content
- Studio introduction and positioning
- Selected work, including the studio's inventory and restaurant demonstration projects when ready
- Services the team can currently deliver
- About the studio
- Working process
- Contact

## Visual direction
Premium, minimal, modern creative-tech. Initial palette direction: charcoal, warm white, and electric blue. Favor clear hierarchy, strong typography, deliberate spacing, and restrained motion.

## Important constraints
- Do not invent clients, testimonials, awards, years of experience, or performance metrics.
- Label concepts, demos, and work in progress accurately.
- Do not publish broken or placeholder project links.
- Contact actions must genuinely work; never simulate a successful enquiry.
- Any private project-management interface must be protected and excluded from public navigation.

## Technical decisions
The implementation stack has not been finalized in this document. Inspect the repository and confirm the chosen stack, package manager, scripts, and deployment target before making assumptions.

- `README.md`: public studio overview and quick start.
