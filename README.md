# ASTRAVA — Studio Portfolio

Official portfolio website for ASTRAVA, an independent digital studio.

> Ideas into digital experiences.

## Purpose

Present the studio, its capabilities, selected work, and a clear contact path. The Inventory Management System and Restaurant Management System are maintained in separate repositories.

## Planned sections

- Hero and studio introduction
- Selected work
- Services the team can currently deliver
- About the studio
- Working process
- Contact

## Preferred technology direction

React, TypeScript, Vite, Tailwind CSS, Lucide icons, and optional Framer Motion. Confirm the stack before treating any dependency as installed.

## Quality expectations

- Responsive and accessible
- Working links and interactions; no fake forms
- No invented clients, testimonials, awards, or metrics
- Never commit secrets or private credentials
- Run available lint, type-check, and production build checks before merging

## Contributions

Use focused feature branches and pull requests. Keep `main` stable and request review from another founder before merging.
